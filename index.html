📖 Как установить

1. Подготовь телевизор.
Включи Developer Mode и Key Server в приложении Developer Mode на LG TV.
2. Подготовь компьютер.
Установи Node.js и webOS CLI. Подключи телевизор и компьютер к одной сети.
3. Настрой подключение.
Добавь телевизор в webOS CLI и настрой ключ подключения.
4. Установи приложение.
В PowerShell выполни команду:
ares-install.cmd --device LGTV .\com.personal.photogallery_1.1.0_all.ipk
5. Запусти приложение.
ares-launch.cmd --device LGTV com.personal.photogallery
